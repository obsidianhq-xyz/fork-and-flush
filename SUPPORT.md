# Fork-and-flush support

Published by Obsidian Labs.

- Email **support@obsidianhq.xyz** for support, private bug reports, and privacy
  requests.
- Open a [GitHub issue](https://github.com/obsidianhq-xyz/skills/issues) for
  a public bug report or suggestion. Include the plugin version, AI host and
  version, expected behavior, and a minimal reproduction.
- Read the [installation instructions](docs/plugins.md) and
  [runtime requirements](plugins/fork-and-flush/README.md#portability).

Do not post API keys, passwords, confidential files, or private transcripts in
public issues. Share only the minimum diagnostic information needed. Our
[privacy policy](PRIVACY.md) explains how support information is handled.

This is an independent open-source project. It is not affiliated with or endorsed
by Microsoft Research, OpenAI, or Anthropic. There is no guaranteed response time.
